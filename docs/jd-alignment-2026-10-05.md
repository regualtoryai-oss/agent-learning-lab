## 课程调整

采用 [十周路线](roadmap.md)：每周 6 小时核心 + 2 小时选修。**TS/Vue 主线贯穿一个 Agent 应用**，DSH 源码帮助理解系统，Codex 只做同一职责的对照。每次阅读连接一个实现或验证任务。

评测提前到第一周；后端、异步、SQL、状态恢复、工具边界、可观测性、成本/延迟和验收报告成为核心。Python/FastAPI 与 MCP 在额外时间中选一个做薄桥接；一次桥接不等于精通 Python 或协议生产运维。

Go/K8s、数据平台、复杂多 Agent、训练调优属于岗位分支。若决定重点投递 J3、J6 或 J9，应在主线之外安排对应的语言与生产实践；不承诺十周内满足全部要求。

## 表达真实能力

学历、指定语言、后端年限、生产经历、客户现场/出差条件应逐项核对。已有前端年限不能直接折算成后台或 ToB 年限。一个项目的多个版本仍是一个项目。

作品 README 分开写：已实现、已验证、计划、已知限制。模型输出结束、工具调用成功与业务验收是分别检查的事件；任务成功率必须附样本量、判定规则和运行条件。模拟数据、Mock、源码推演与真实模型运行分别标注。
