# 合成资料包

以下全部虚构。段落编号用于练习引用，不代表真实产品事实。

## 材料目录

| ID | 标题 | 索引提示 |
| --- | --- | --- |
| `plan-a` | A：本地关键词检索与模板回答 | 工期、月成本、回答方式、出处 |
| `plan-b` | B：本地向量检索与本地模型 | 工期、本地运行、效果 |
| `plan-c` | C：混合检索与云模型 | 工期、月成本、数据流向 |
| `a-evaluation` | A的效果测试说明 | 测试集、准确率口径 |
| `b-environment` | B的安装与环境说明 | 硬件、估算范围、效果测试集 |
| `c-cost` | C的费用说明 | 固定费用、模型调用、问答量 |
| `b-environment-backup` | B环境说明的备用副本 | 与原说明相同，故障演练时可用 |

## plan-a

- A-P1：预计2个工作日交付原型，总月成本80元。检索和回答都在本机完成。
- A-P2：使用关键词匹配和预设模板，未匹配时返回“未找到”；可附原文文档ID与段落定位。
- A-P3：宣传页称测试准确率95%，没有说明测试问题的分布；详细记录见`a-evaluation`。

## plan-b

- B-P1：使用本地向量检索和本地模型；原文与片段不离开本机，回答支持出处。
- B-P2：预计6个工作日，费用栏写“本地免费”；没有列出硬件或额外资源成本。
- B-P3：效果栏写准确率88%；安装条件、估算范围和测试说明见`b-environment`。

## plan-c

- C-P1：混合检索后调用云模型，预计5个工作日；月成本栏写260元。
- C-P2：不上传完整文档，只把与问题相关的片段发送给云模型。
- C-P3：宣传页写准确率92%、引用率100%；费用口径见`c-cost`，效果测试方法未提供。

## a-evaluation

- AE-P1：准确率95%来自20道包含原文关键词的问题。
- AE-P2：没有测试同义表达、跨文档比较和资料不足场景；此数据不能直接证明这些场景的效果。

## b-environment

- BE-P1：当前版本要求16GB显存；现有机器配置未确认。
- BE-P2：6个工作日的估算不包含模型环境安装与硬件采购。
- BE-P3：“本地免费”指没有模型服务调用费；没有估算设备和运维成本。
- BE-P4：88%来自100道同义表达问题，与A的测试集不同。

## c-cost

- CC-P1：260元只包含固定服务费用，不含模型调用费。
- CC-P2：模型调用费受问答次数、输入和输出长度影响；这些用量未提供，因此总月成本尚不能确认。

## 故障与需求变化卡

演练到读取环境说明时，可选择注入一次`READ_TIMEOUT`；索引中仍存在`b-environment-backup`，内容与BE-P1至BE-P4相同。请按自己的错误策略决定停止、有限重试、使用副本或请求协助，并保留决策依据。

也可在中途补充模拟用户信息：“现有机器只有8GB显存，不新增硬件预算。”观察这项新约束如何改变计划。此信息仅为演练卡，不是仓库作者或学习者的真实机器配置。
